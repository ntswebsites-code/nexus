# DOMAIN MODEL (from the 5D draft)

Legend: **N** = exists in the Nexus schema today (`backend-audit.md` 2.8/2.3/2.6); **NV** = exists in NVCCZ (`prisma/schema.prisma` or raw-SQL tables); **P** = proposed new table/column for Nexus. Types are indicative (MySQL 8): `id` cuid/uuid, money `DECIMAL(20,4)` (NVCCZ uses `DECIMAL(15,2)`; platform standard applies), dates `DATE`, timestamps `DATETIME(3)`. All company-owned rows carry `company_id` and are returned only for the caller's active company (out-of-scope id → 404).
