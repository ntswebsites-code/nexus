# API CONTRACT (from the 5D draft)

Conventions. NVCCZ routes are prefixed `/api` (e.g. `/api/applicant/profile`); envelope `{success, message, data, timestamp}` (errors `{success:false, message}`); auth = bearer/JWT `authenticate`. "isApplicant" = the user's e-mail equals some `applications.applicantEmail` (403 text "Access denied. This endpoint is only available to applicants."); "applicantRole" = `requireApplicantRole()` (role name `applicant` or role code `APPLICANT`; 403 "Forbidden: applicants only"). The last column gives the proposed Nexus path (`/api/v1/company/...`, guard *session + company context*, section 4.4; errors use the Nexus code catalogue: `no_company_access`, `not_found`, `invalid_state`, `version_conflict`, `sod_violation`, `payload_too_large`, `permission_denied`). Status vocabulary: **exists** (implemented in NVCCZ), **absent** (no implementation), **asked** (written up as a backend ask in `investee-portal-v8-backend-asks.md`), **partial** (exists with defects/limits).
